## Coupling Bottlenecks

- **Selection and evidence are coupled:** Explore’s inventory feeds both static indexing and file choice; static mode ranks task-term seeds and adds directly connected import/name-call files, then `choose_files` takes the ranked candidates ([scripts/adapters/aider_explore.py#L31](scripts/adapters/aider_explore.py#L31), [scripts/adapters/explore_evidence.py#L138](scripts/adapters/explore_evidence.py#L138), [scripts/adapters/explore_evidence.py#L149](scripts/adapters/explore_evidence.py#L149), [scripts/adapters/aider_explore.py#L172](scripts/adapters/aider_explore.py#L172)). Hypothesis: shallow edges and filename/term ranking may omit relevant callers; completeness was not measured.
- **Source-reading coverage is bounded:** files are chunked by a character limit; when there are too many chunks, the algorithm can skip middle chunks and labels coverage partial ([scripts/adapters/aider_explore.py#L112](scripts/adapters/aider_explore.py#L112), [scripts/adapters/aider_explore.py#L156](scripts/adapters/aider_explore.py#L156)). Model notes and rewritten memory are then used downstream ([scripts/adapters/aider_explore.py#L128](scripts/adapters/aider_explore.py#L128), [scripts/adapters/aider_explore.py#L219](scripts/adapters/aider_explore.py#L219)). Hypothesis: this compression can lose relevant caller or evidence detail; frequency is unknown.
- **Report checks have different strengths:** Explore validates citation path safety, file existence, line bounds, and—when supplied—whether citations fall within inspected spans ([scripts/adapters/aider_explore.py#L228](scripts/adapters/aider_explore.py#L228)). Worker’s research audit checks a nonempty headed report and task metadata, then checks up to five citation matches for line bounds ([scripts/worker_runtime.py#L2290](scripts/worker_runtime.py#L2290), [scripts/worker_runtime.py#L2312](scripts/worker_runtime.py#L2312)). Neither check proves semantic entailment; Worker’s cited-line check does not require inspected-span membership.
- **Protocol boundary is another seam:** Aider parses the last supported JSON outcome from chat history, converts missing or malformed outcomes to failure, and requires a commit message for `complete` ([scripts/adapters/aider.py#L192](scripts/adapters/aider.py#L192), [scripts/adapters/aider.py#L225](scripts/adapters/aider.py#L225), [scripts/adapters/aider.py#L294](scripts/adapters/aider.py#L294)). Worker separately audits research output and publishes declared report artifacts after a passing audit ([scripts/worker_runtime.py#L2032](scripts/worker_runtime.py#L2032), [scripts/worker_runtime.py#L2035](scripts/worker_runtime.py#L2035)).
